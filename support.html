MD Viewer for Chrome

Local .md files don't render

Open chrome://extensions, click Details on MD Viewer and turn on Allow access to file URLs. Then reload the file.

Pasting plain text instead of Markdown

Smart paste converts formatted content into Markdown. To paste plain text instead, press Ctrl + Shift + V, or turn off Smart paste in the editor's bottom bar.

Right-click conversion doesn't work on a page

Chrome doesn't let extensions read its own pages (chrome://), the Chrome Web Store or built-in PDF viewers. Everywhere else, select text or right-click the page and choose a MD Viewer option.
